# AI-Chatbot
Python tech stack for an AI chatbot that can be trained with data of the users choosing

Prerequisites:

* Ensure the latest version of python is installed in your terminal
* Installation of a text editor (Ex: vim, nano, etc)

Download:

* To download, simply type "git clone https://github.com/RavenTheBird789/AI-Chatbot" in your terminals command line

Executing the software:

To run the program, simply type "python3 main.py" in your terminals command line (Note: a shortcut can be created in a terminal session using the bash alias command to run the program faster. Ex: alias run="python3 main.py")

Notes For Usage:

* Even after the program finishes executing, the training data will be stored locally on the users device within the J_AI directory as differently named text files
* If the user is dissatisfied with the results of the training data, the aforementioned installed text editor can be used to modify the contents of the text files
* Since this project is open source, once installed on the users device, modifications can be made as the user sees fit; such as implimenting additional features
